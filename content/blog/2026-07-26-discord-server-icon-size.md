# Make a Discord Server Icon From Your Logo (512×512)

A Discord server icon should be **512×512 pixels and square**. Discord then crops it into a circle, so the trick isn't really the size — it's making sure your logo sits cleanly inside that circle instead of getting its corners clipped. Here's how to turn your logo into a server icon that looks right.

## The size

Upload your server icon at **512×512**. Discord's minimum is 128×128, but 512 gives you a crisp icon on high-resolution screens, and Discord downscales it cleanly for the small versions in the server list. There's no reason to go smaller — bigger source, sharper result everywhere it appears.

## The circle crop is the real constraint

Discord displays server icons as **circles**, not squares. That means the four corners of your 512×512 image get cut off, and anything you put out there disappears. So:

- **Centre the mark** and keep it within the middle of the square, roughly inside the circle that fits the image.
- **Leave a little breathing room** around it, so the circular crop doesn't shave the edges of a wide wordmark or a tall symbol.

If your logo is a compact symbol, this is easy. If it's a wide wordmark, consider using just the symbol or monogram for the server icon — wide logos and circular crops don't get along, and the icon is tiny in the server list anyway.

## Transparent or solid background?

Both work, and it's a look choice:

- **Transparent** — your mark floats on Discord's own background inside the circle, which shifts slightly between light and dark themes. Clean and minimal.
- **Solid background** — put the mark on a brand colour, and the circle is a consistent, filled disc on every theme. More branded, more uniform.

Autocropper gives you the clean, background-free mark on a transparent square; if you want the solid version, drop that mark onto a brand-colour background before uploading.

## How to make it from your logo

1. Drop your logo into the tool at the top of this page — drag, file picker, or paste from clipboard.
2. It removes the flat background, cleans the edges (no white halo), crops to the mark, and centres it on a transparent square.
3. Download the **512** size and upload it to your server settings → Overview → server icon.

The whole thing runs in your browser — nothing is uploaded — and you get the rest of the square icon sizes in the same pass if you need them elsewhere.

One thing this doesn't do: **animated icons.** Boosted Discord servers can use an animated GIF icon; Autocropper produces a static PNG. For a still icon from your logo, it's a one-drag job; for an animated one you'll need a GIF made elsewhere.

## FAQ

**What size is a Discord server icon?**
512×512 pixels is the recommended size. The minimum is 128×128, but 512 stays crisp on high-resolution screens and downscales cleanly.

**Why does my server icon look cut off?**
Discord crops server icons into a circle, so the corners of a square image are removed. Keep your mark centred with some margin so nothing important lands in the corners.

**Should the icon be transparent?**
Your choice. A transparent mark sits on Discord's background inside the circle; a solid background gives a consistent filled disc across themes.

**Can I use the same image as my Discord avatar?**
Yes — user avatars are also square and circle-cropped, so a centred 512 works for both.

**Is my logo uploaded to make the icon?**
No. Background removal, cropping and resizing run in your browser tab; nothing is sent to a server.
